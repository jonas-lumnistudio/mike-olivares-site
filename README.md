# Mike Olivares · Professional EOS Implementer

Homepage prototype for Mike Olivares, Professional EOS Implementer serving Houston, Austin and San Antonio, Texas.

## What's here

- `index.html` – the whole homepage in one file (HTML, CSS and JavaScript). All photos are embedded, so it needs no other files to run.
- `logo/` – the signature logo as SVG: dark version, white version for dark backgrounds, and the "MO" monogram.

## Going live

It's a static page, so any static host works with no build step:

- **Netlify / Vercel / Cloudflare Pages:** import this repository, leave the build command empty, and set the output/publish directory to the repository root.
- **GitHub Pages:** Settings → Pages → deploy from branch `main`, folder `/ (root)`. On a free plan, GitHub Pages requires the repository to be public.
